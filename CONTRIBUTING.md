# Contribution Guide

Thank you for your interest in contributing to **Spotitube**! This document outlines the guidelines and best practices for contributing to the project.

> [!NOTE]
> Before you begin, make sure to read and understand our [Code of Conduct](CODE_OF_CONDUCT.md).

## How to Contribute

### Reporting Bugs

We track bugs using [GitHub Issues](https://github.com/armory31/armoryProyect/issues). Before creating a new issue, please search existing issues to see if the problem has already been reported.

### Suggesting Features

We also handle feature suggestions through [GitHub Issues](https://github.com/armory31/armoryProyect/issues).

### Submitting Pull Requests

1. **Fork the repository** and create a feature branch.
2. **Implement your changes**.
3. **Submit your pull request** with a clear description.

## Development Environment Setup

1. **Clone the repository**:
   ```bash
   git clone https://github.com/armory31/armoryProyect.git
   cd armoryProyect
   ```
2. **Build the project using Gradle**:
   ```bash
   ./gradlew build
   ```

Thank you for contributing to **Spotitube**!
